# Customer Behavior Data Analyst Portfolio Project
# Data Analytics Project

## Overview

This project demonstrates an end-to-end **data analytics process** that transforms raw data into meaningful insights. The workflow includes loading the dataset, performing exploratory data analysis (EDA), cleaning and preparing the data, executing SQL queries for analysis, building an interactive dashboard, and presenting the results through a report and presentation. The project highlights how different data tools can be integrated to support data-driven decision-making.

## Dataset

The dataset used in this project consists of structured data suitable for analytical tasks. It contains multiple attributes that help in identifying patterns, trends, and relationships within the data. During the analysis process, the dataset is examined for inconsistencies such as missing values, duplicate records, and incorrect formats so that the data can be prepared for accurate analysis and visualization.

## Tools and Technologies

Several tools and technologies were used to complete the project. Python was used for loading the dataset, performing exploratory data analysis, and cleaning the data. SQL databases such as PostgreSQL, MySQL, and SQL Server were used to store the processed data and run analytical queries. Power BI was used to create interactive dashboards and visualizations that make the insights easier to understand. Gamma was used to prepare a professional presentation summarizing the results of the analysis.

## Project Steps

### Data Loading

The first step in the project involves importing the dataset into Python. This allows the data to be inspected, understood, and prepared for analysis. The structure of the dataset, column names, and data types are reviewed to gain an initial understanding of the information available.

### Exploratory Data Analysis (EDA)

Exploratory Data Analysis is performed to understand the distribution, trends, and relationships within the data. During this stage, summary statistics and visualizations are used to explore the dataset. EDA helps in identifying patterns, detecting anomalies, and determining which variables are important for further analysis.

### Data Cleaning

Before performing deeper analysis, the dataset must be cleaned to ensure accuracy and reliability. This includes handling missing values, removing duplicate records, correcting inconsistent data entries, and ensuring that data types are properly formatted. Clean data improves the quality of the analysis and leads to more reliable insights.

### SQL Analysis

After the data is prepared, it is stored in a relational database system such as PostgreSQL, MySQL, or SQL Server. SQL queries are then used to perform analytical operations such as filtering data, grouping records, calculating aggregates, and joining tables when required. SQL helps extract meaningful insights directly from the database.

### Dashboard Development

An interactive dashboard is created using Power BI to visualize the results of the analysis. The dashboard presents key insights using charts, graphs, and key performance indicators. Interactive features such as filters and slicers allow users to explore the data dynamically and gain a deeper understanding of the results.

### Report and Presentation

To effectively communicate the findings, a detailed report is prepared summarizing the analysis, methodology, and insights obtained from the data. In addition, a presentation is created using Gamma to clearly explain the project objectives, analytical process, and results to stakeholders.

## Results

The project produces meaningful insights that help in understanding trends and patterns present in the dataset. The visualizations and SQL analysis highlight important relationships between variables and support data-driven conclusions. The dashboard and report together provide a clear and structured representation of the analytical findings.

## How to Run the Project

To run this project, the dataset is first loaded into Python for preprocessing and exploratory analysis. After cleaning and preparing the data, it is stored in a relational database where SQL queries are executed to perform further analysis. Finally, the processed data is connected to Power BI to build interactive dashboards. The results are documented in a report and presented through a presentation for easy interpretation.
